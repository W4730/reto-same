# Reto Same v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** App de campo (Expo Go) + web pública (Vite PWA) sobre Supabase, alcance P1.
**Architecture:** Monorepo npm workspaces. Lógica de dominio pura en `packages/shared`; reglas de datos en migraciones SQL (RLS + triggers + vistas); cada app es un cliente delgado.
**Tech Stack:** Expo SDK (expo-router, expo-location, expo-camera, expo-image-manipulator, expo-file-system, @react-native-async-storage/async-storage, @react-native-community/netinfo, react-native-maps), Vite + React + TS, vite-plugin-pwa, maplibre-gl, @supabase/supabase-js, PostGIS.
**Spec:** [docs/superpowers/specs/2026-11-25-reto-same-app-design.md](../specs/2026-11-25-reto-same-app-design.md) + [handout.md](../../../handout.md)

## Global Constraints
- Colores: `#194171` primario, `#1E3A52` texto, `#1796A6` acento (solo texto ≥ 24 px), `#0F7480` links/botones con texto blanco, `#21A8B4` nunca con texto.
- Fuentes: Montserrat 700 titulares, Roboto 400/500/700 cuerpo; nunca < 400 en texto funcional.
- Estados: `pendiente | activo | por_eclosionar | eclosionado | perdido`; marcadores según sección 15 (forma + color).
- Ventana de eclosión: 45–60 días, referencia 53. Se muestra como rango.
- Código: `S{YY}-{NNNN}` por temporada; temporada `2026-2027` empieza el 1 de julio.
- Teléfono SOS: `+593984281540`.
- Voz: tuteo, español.
- Todo lo de campo debe correr en Expo Go (sin módulos nativos fuera del SDK).

## Review Focus
- GPS sin permiso o sin fijar: el registro no avanza y explica por qué (Task 4).
- App cerrada con cola pendiente: al reabrir, la cola sigue y se envía (Task 3 test `queue persists`).
- Reintento tras fallo a mitad (foto subida, fila no): el reintento no duplica (upsert por id, Task 3).
- Coordinador intenta mover un nido validado: la base lo rechaza (Task 2 SQL check).
- Turista anónimo consulta `nests`: recibe 0 filas (Task 2 SQL check).
